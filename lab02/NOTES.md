Рабочая папка - это текущие файлы в проекте, с которыми непосредственно идет работа.
Индекс - это промежуточная область, куда добавляются изменения с помощью команды git add перед коммитом.
Коммит - это зафиксированный снимок индекса в истории репозитория.
Git - это система контроля версий, благодаря git можно удаленно управлять репозиториями.
Github - это облачная платформа, на которой можно хранить репозитории.
