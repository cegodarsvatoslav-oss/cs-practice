Рабочая папка - это файловая система (папка на вашем жестком диске) с проектом, в которой вы непосредственно редактируете, создаете и удаляете файлы. Индекс - это промежуточная область, в которой хранится информация об изменениях в рабочей папке, которые пойдут в следующий коммит. Коммит - зафиксированное изменение проекта.
Разница в том, что github - облачная платформа, где можно хранить проекты. Git - это программа, с помощью которой можно удаленно работать с проектами, которые находятся на github
git status - показывает общее состояние проекта. git diff - показывает изменениы, которые еще не были добавлены в индекс. git diff --staged - показывает изменениы, которые добавили в индекс, но еще не закоммитили
Ветка - отдельная линия разработки. При новом коммите указатель ветки переходит на этот самый новый коммит. Слияние обьединяет изменения из одной ветки в другую.
