git - программа, позволяющая удаленно управлять репозиториями.
github - облачная платформа, на которой хранятся репозитории.   
git diff - показывает разницу между рабочей директорией и индексом.
git diff --staged - показывает изменения, которые уже добавлены в индекс, но еще не закоммичены.
git status - показывает текущее состояние рабочей директории и индекса.
Ветка - это независимая линия разработки.
При новом коммите указатель текущей ветки автоматически сдвигается вперед - на новый коммит.
Слияние объединяет изменения одной ветки в другую.
